# Wallaby Features Documentation - 2026-04-03

## Core Application
- **Technology**: Electron-based desktop AI chat application
- **Integration**: Ollama API for language model interactions
- **UI**: Modern gradient backgrounds with responsive design
- **Storage**: electron-store with partitioned storage (`persist:wallaby`)

---

## 1. Chat Interface

### UI Features
- Clean, modern interface with gradient backgrounds
- Message bubbles: user (left), AI (right) with distinct styling
- Timestamps on every message (HH:MM format)
- Auto-scrolling to latest message
- Smooth animations and transitions
- Responsive design for various screen sizes

### Message Handling
- **Plain text** for user messages
- **Markdown rendering** for AI responses (commonmark + dompurify)
- **Auto-resizing textarea** that grows/shrinks with input
- Send via **button** OR **Enter key** (Shift+Enter for newlines)
- ⚠️ **Input not auto-reset after send** - textarea cleared but height not restored

### Image Attachments
- Attach button opens file picker
- Thumbnail previews in attach-container
- Remove button (×) on each attachment
- Converts to base64 before API call
- Auto-cleanup after successful transmission
- ⚠️ **OCR not yet implemented** - `window.ocr.recognize()` referenced in code but not functional

### Command System
- Slash command recognition (`/export`, `/exit`, etc.)
- Currently stubbed with placeholder messages

---

## 2. Settings Page

### Configuration Options
- **Theme**: Light / Dark / Auto (system preference)
- **Language**: Multi-language support
- **AI Model Selection**: Dropdown populated from Ollama API
- **Temperature Slider**: Creativity control (0.5 - 1.0)
- **Save History**: Toggle to persist chat history
- **Auto Save**: Automatic configuration persistence
- **Analytics**: Privacy toggle (disabled by default)
- **Ollama Endpoint**: Custom API base URL
- **Prepend/Append Prompts**: System prompt injection layers
- **Max Tokens**: Response length limit (default: 1000)
- **Timeout**: API connection timeout (default: 30s)

### Actions
- **Save Button**: Persists all settings to electron-store
- **Reset Button**: Restores factory defaults with confirmation dialog
- **Reload Models**: Fetches latest models from `/api/tags` endpoint

---

## 3. File Storage System (IPC)

### Capabilities
- `saveFromPath`: Copy file from filesystem to temp storage
- `readBase64`: Retrieve file as base64 data URL
- `save`: Write content directly to temp storage
- `read`: Get file contents as UTF-8 string
- `delete`: Remove temp file and update store
- `list`: Enumerate all stored files

### Storage Details
- Temporary directory in app data path (`temp-files/`)
- Unique keys with timestamp + random suffix
- MIME type detection from file extension
- Automatic cleanup after successful API transmission
